- 자체 스킬 `design-patterns` §9 에 CodeIgniter 4 형태(Config\Services 조립, Model 생성자로 연결 전달, Service 메서드 안의 트랜잭션)를 넣었다. CodeIgniter 전용으로 신뢰 기준(공식 또는 별 1천 이상·3개월 내 커밋·라이선스)을 충족하는 설계 패턴 스킬은 찾지 못했다.
