## 4. 관련 스킬 추가(이 플러그인 안)

신뢰 기준을 만족하면서 pytest 3계층·uv·FastAPI 레이어 규칙을 한 번에 다루는 외부 스킬이 없어 직접 작성했다. 모두 `plugins/stage-pilot/skills/`.

| 스킬 | 내용 |
|---|---|
| `fastapi-conventions` | uv init/add/sync/run, 디렉터리 기본안, 레이어 규칙과 패턴(DI·Service·Repository·DTO·Settings·도메인 예외), ruff 설정, 상태 코드 |
| `fastapi-testing` | 단위·API·통합 경계, conftest 픽스처로 같은 환경, 테스트 하나에 동작 하나, 흐름 테스트 예외, 「테스트 계층」 보고 형식 |
| `fastapi-security` | 설계 보안 경계 표, OWASP API Top 10 대응 기본값, 도구 결과 대조표 |
| `work-memory` | `stage.js task`·`log`로 작업·하위 작업·결정 기록, 세션 재개·서브에이전트 위임 규칙 |
