이 저장소의 플러그인 2종을 설치·전환·업데이트·제거하는 명령을 한곳에 모았습니다. 각 블록은 그대로 복사해 입력하면 됩니다. 별도 표시가 없는 명령은 Claude Code 세션 안에서 입력합니다.

0. 두 가지 판

판브랜치stage-pilotlegacy-onboarding-manual쓰는 경우
기본판main0.3.20.1.0Python·FastAPI 프로젝트
PHP 지원판php0.3.40.1.1PHP·CodeIgniter 레거시도 다룰 때
두 판은 동시에 등록할 수 없습니다. 마켓플레이스 이름(claude-plugin-for-fastapi)이 같기 때문입니다. 마켓플레이스는 등록할 때 정한 브랜치만 따라가므로, 업데이트로는 판이 바뀌지 않습니다. 판을 바꾸려면 3. 판 바꾸기처럼 지우고 다시 등록합니다.

1. 기본판 설치 (main)

/plugin marketplace add bluebamus/claude-plugin-for-fastapi
/plugin install stage-pilot@claude-plugin-for-fastapi
/plugin install legacy-onboarding-manual@claude-plugin-for-fastapi
/reload-plugins

install 줄은 플러그인 정보 화면을 엽니다. 설치 범위(사용자·프로젝트·로컬)를 고르면 설치됩니다. 필요한 플러그인만 골라 설치해도 됩니다.

2. PHP 지원판 설치 (php)

처음 설치할 때 입력합니다. 주소 끝의 #php가 php 브랜치를 고릅니다.

/plugin marketplace add bluebamus/claude-plugin-for-fastapi#php
/plugin install stage-pilot@claude-plugin-for-fastapi
/plugin install legacy-onboarding-manual@claude-plugin-for-fastapi
/reload-plugins

PHP 프로젝트에는 PHP, Composer, PHPUnit이 필요합니다. 완료 확인이 vendor/bin/phpunit을 찾으므로 프로젝트에서 다음을 실행해 둡니다.

composer require --dev phpunit/phpunit

3. 판 바꾸기

기본판 → PHP 지원판

/plugin marketplace remove claude-plugin-for-fastapi
/plugin marketplace add bluebamus/claude-plugin-for-fastapi#php
/plugin install stage-pilot@claude-plugin-for-fastapi
/plugin install legacy-onboarding-manual@claude-plugin-for-fastapi
/reload-plugins

PHP 지원판 → 기본판

/plugin marketplace remove claude-plugin-for-fastapi
/plugin marketplace add bluebamus/claude-plugin-for-fastapi
/plugin install stage-pilot@claude-plugin-for-fastapi
/plugin install legacy-onboarding-manual@claude-plugin-for-fastapi
/reload-plugins
  • 마켓플레이스를 지우면 거기서 설치한 플러그인도 함께 제거되므로, 플러그인을 따로 지울 필요가 없습니다.
  • 설치 범위는 예전과 같은 범위를 고릅니다.
  • 프로젝트의 .claude/stage-pilot/state.json과 docs/의 단계 문서는 그대로 남습니다. 다시 설치한 뒤 하던 트랙을 이어갈 수 있습니다.

4. 셸에서 설치 (세션 밖, 스크립트용)

PHP 지원판 예시입니다. 기본판은 #php를 빼면 됩니다. 처음 설치라면 첫 줄은 빼도 됩니다.

claude plugin marketplace remove claude-plugin-for-fastapi
claude plugin marketplace add bluebamus/claude-plugin-for-fastapi#php
claude plugin install stage-pilot@claude-plugin-for-fastapi
claude plugin install legacy-onboarding-manual@claude-plugin-for-fastapi
  • 기본 설치 범위는 사용자 범위입니다. 프로젝트 범위로 설치하려면 install 줄 끝에 --scope project를 붙입니다.
  • 설치한 플러그인은 다음 세션부터, 또는 열린 세션에서 /reload-plugins를 실행한 뒤부터 적용됩니다.

5. 로컬 클론으로 설치 (판을 자주 바꿀 때)

git clone -b php https://github.com/bluebamus/claude-plugin-for-fastapi C:/work/claude-plugin-for-fastapi
/plugin marketplace remove claude-plugin-for-fastapi
/plugin marketplace add C:/work/claude-plugin-for-fastapi
/plugin install stage-pilot@claude-plugin-for-fastapi
/plugin install legacy-onboarding-manual@claude-plugin-for-fastapi

첫 줄은 셸에서, 나머지는 세션에서 입력합니다. 로컬 경로로 등록한 마켓플레이스는 폴더의 파일을 바로 읽습니다. 그래서 이후에는 다시 설치할 필요 없이, 그 폴더에서 브랜치를 바꾸고 다시 불러오기만 하면 됩니다.

git checkout php        # 또는 git checkout main
/reload-plugins

GitHub의 새 버전은 자동으로 오지 않으므로 그 폴더에서 git pull로 받습니다.

6. 설치 없이 한 번만 써 보기

전역 설정을 바꾸지 않고 이번 실행에만 불러옵니다. 셸에서 입력합니다.

claude --plugin-dir C:/work/claude-plugin-for-fastapi/plugins/stage-pilot

7. 업데이트

이 마켓플레이스는 자동 업데이트가 기본으로 꺼져 있습니다. 다음 중 하나로 새 버전을 받습니다.

  • 한 번에: /plugin → Marketplaces 탭 → claude-plugin-for-fastapi → Update marketplace
  • 플러그인 하나만: /plugin → Installed 탭 → 플러그인 → Update now, 또는 셸에서 아래 명령
  • 자동으로: Marketplaces 탭에서 이 마켓플레이스를 고르고 Enable auto-update를 켭니다
claude plugin update stage-pilot@claude-plugin-for-fastapi
claude plugin update legacy-onboarding-manual@claude-plugin-for-fastapi

업데이트 뒤에는 /reload-plugins를 실행하거나 세션을 다시 엽니다.

/plugin marketplace update claude-plugin-for-fastapi는 목록만 새로 받습니다. 설치된 플러그인은 그대로이므로, 이 명령만으로는 새 버전이 적용되지 않습니다.

8. 여러 세션에 적용

같은 프로젝트에 세션을 여러 개 띄워 두었다면, 한 세션에서 설치한 뒤 나머지 세션에서 각각 다시 불러오기만 하면 됩니다. 다시 설치할 필요는 없습니다.

/reload-plugins
  • 프롬프트 캐시 경고와 함께 적용이 보류되면 /reload-plugins --force를 실행합니다.
  • git worktree에서 도는 세션에 적용되지 않으면, 프로젝트·로컬 범위 설치가 그 폴더에 보이지 않는 것입니다. /plugin의 Installed 탭에서 지우고 Install for you (user scope)로 다시 설치합니다.
설치 범위기록 위치보이는 세션
사용자 (user)~/.claude/settings.json이 컴퓨터의 모든 프로젝트, 모든 세션
프로젝트 (project)<프로젝트>/.claude/settings.json같은 폴더에서 실행한 세션
로컬 (local)<프로젝트>/.claude/settings.local.json같은 폴더에서 실행한 세션

9. 제거

/plugin uninstall stage-pilot@claude-plugin-for-fastapi
/plugin uninstall legacy-onboarding-manual@claude-plugin-for-fastapi
/plugin marketplace remove claude-plugin-for-fastapi

마지막 줄은 마켓플레이스 등록을 해제합니다. 거기서 설치한 플러그인도 함께 제거되므로, 이 줄만 실행해도 됩니다.

10. 설치 확인

/stage-pilot:stage profiles
  1. greenfield, feature, enhance, default 네 줄이 나오면 stage-pilot이 설치된 것입니다.
  2. /plugin의 Installed 탭이나 셸의 claude plugin list에 나오는 버전으로 판을 구분합니다. 기본판은 0.3.2 / 0.1.0, PHP 지원판은 0.3.3 이상 / 0.1.1입니다.
  3. /plugin의 Marketplaces 탭에서 출처를 확인합니다. PHP 지원판은 ...#php로 보입니다(로컬 클론은 로컬 경로).

11. 함께 쓸 플러그인 (stage-pilot 수행 모드용, 선택)

stage-pilot의 수행 모드는 단계마다 다른 플러그인을 호출합니다. 설치되지 않았어도 제안 모드는 동작하고, 단계 카드에 설치 명령이 나옵니다. 자주 쓰는 세 가지는 다음과 같습니다.

/plugin install superpowers@claude-plugins-official
/plugin install feature-dev@claude-plugins-official
/plugin install code-modernization@claude-plugins-official

전체 목록과 각 플러그인의 쓰임은 stage-pilot 사용 매뉴얼 3장에 있습니다. 설치만 하고 꺼 둔 플러그인은 Claude가 쓸 수 없으니 /plugin에서 켜져 있는지 확인합니다.
